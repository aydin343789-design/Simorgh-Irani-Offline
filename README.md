# Simorgh Irani Offline | سیمرغ

اپلیکیشن Android آموزش انگلیسی با تمرین مکالمه، مترجم فارسی ↔ انگلیسی و موتور گفتار انگلیسی داخلی.

## قابلیت‌ها

- ترجمهٔ جمله‌های آزاد فارسی ↔ انگلیسی با Google ML Kit روی دستگاه
- دانلود یک‌بارهٔ مدل فارسی فقط پس از تأیید صریح کاربر و فقط از طریق Wi‑Fi؛ انگلیسی در ML Kit داخلی است
- جلوگیری از نمایش خروجی ترجمهٔ مخلوط یا خارج از زبان مقصد
- موتور گفتار Sherpa-ONNX/Piper با صدای انگلیسی Amy (کیفیت medium، مدل INT8) که همراه APK بسته‌بندی می‌شود
- پخش گفتار انگلیسی بدون استفاده از Text-to-Speech سیستم Android یا سرویس گفتار مرورگر؛ برای فارسی موتور گفتار ارائه نمی‌شود
- مکالمه‌های آماده، واژگان، پیشرفت و تاریخچهٔ محلی

## مترجم و رفتار شبکه

در شروع فقط عبارت‌های دقیق و واژه‌های شناخته‌شده از واژه‌نامهٔ کوچک داخلی ترجمه می‌شوند. برای جمله‌های آزاد، برنامه مدل فارسی ML Kit را پس از تأیید داخل برنامه و فقط روی Wi‑Fi می‌گیرد (حدود ۳۰MB طبق مستندات Google؛ مدل انگلیسی از قبل داخلی است). تا وقتی مدل دریافت نشده، جملهٔ ناشناخته به‌صورت ترجمهٔ ناقص یا مخلوط نشان داده نمی‌شود.

پس از نصب مدل، ترجمه روی دستگاه اجرا می‌شود و متن/نتیجه برای ترجمه به Google فرستاده نمی‌شود. بااین‌حال، طبق شرایط ML Kit، خود SDK ممکن است گاهی برای آمار استفاده، رفع اشکال یا اطلاعات/به‌روزرسانی مدل با سرورهای Google ارتباط برقرار کند؛ بنابراین «قطع کامل همهٔ اتصال‌های شبکه بعد از نصب» تضمین‌شدنی نیست. مجوز `INTERNET` فقط برای این قابلیت ML Kit وجود دارد. کیفیت ترجمه نیز مانند هر مدل ماشینی تضمین بی‌نقص ندارد؛ این سرویس برای ترجمهٔ روزمره طراحی شده است.

## گفتار انگلیسی

صدای Amy و مدل Sherpa-ONNX/Piper همراه APK قرار می‌گیرند. مدل در زمان ساخت دریافت و با SHA-256 اعتبارسنجی می‌شود؛ هنگام اجرای اپ هیچ درخواست شبکه‌ای برای موتور گفتار انجام نمی‌شود. موتور فارسی ندارد و برنامه به Text-to-Speech سیستم Android یا گفتار مرورگر fallback نمی‌کند. فایل‌های بومی JNI فعلی برای `arm64-v8a` بسته‌بندی شده‌اند.

## ساخت

نیازمندی‌ها: Node.js، Python 3، Java 21 و Android SDK.

```bash
npm ci
npm run sync
cd android
./gradlew assembleDebug
```

`npm run sync` مدل گفتار انگلیسی را از منبع رسمی در زمان ساخت دریافت/اعتبارسنجی و در assets قرار می‌دهد؛ این دانلود در زمان اجرای اپ انجام نمی‌شود. GitHub Actions نیز workflowهای ساخت APK را در `.github/workflows/` دارد.

نسخهٔ فعلی Android: `1.3` (versionCode `4`). پیش از انتشار، APK را روی یک گوشی واقعی arm64 بررسی کنید، به‌ویژه راه‌اندازی ML Kit، دانلود مدل فارسی روی Wi‑Fi، ترجمهٔ دوطرفه و پخش صدا در حالت پرواز.
