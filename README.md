# Simorgh Irani Offline | سیمرغ

اپلیکیشن Android برای آموزش زبان انگلیسی و ترجمهٔ **فارسی ↔ انگلیسی** با استفاده از Google ML Kit On-device Translation.

## قابلیت‌ها

- ترجمهٔ کلمه و جمله بین فارسی و انگلیسی
- اجرای ترجمه روی خود دستگاه پس از دریافت مدل زبان
- بدون API ترجمه یا سرور اختصاصی در زمان استفاده
- رابط مناسب Android بر پایهٔ Capacitor
- ساخت خودکار APK آزمایشی با GitHub Actions

## نکتهٔ مهم دربارهٔ آفلاین بودن

مدل فارسی در اولین فعال‌سازی ممکن است با اجازهٔ کاربر و از طریق اینترنت دانلود شود. پس از دریافت مدل، ترجمه روی دستگاه و بدون اتصال دائمی به اینترنت انجام می‌شود. بهتر است دریافت اولیهٔ مدل با Wi‑Fi انجام شود.

## ساخت و اجرا

```bash
npm install
npm run build
npx cap sync android
```

در Android Studio پروژهٔ `android/` را باز کنید، یا در محیط دارای Android SDK اجرا کنید:

```bash
cd android
./gradlew assembleDebug
```

workflow موجود در `.github/workflows/build-debug.yml` نیز برای ساخت APK و انتشار آن به‌عنوان artifact آماده شده است.
