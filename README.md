# Simorgh Irani Offline | سیمرغ ایرانی

اپلیکیشن Android برای آموزش زبان انگلیسی، تمرین مکالمه و ترجمهٔ **فارسی ↔ انگلیسی**.

## قابلیت‌ها

- درس‌ها، فلش‌کارت‌ها، آزمون‌ها و مرور هوشمند کاملاً محلی
- ترجمهٔ آنلاین رایگان فارسی ↔ انگلیسی با MyMemory؛ در صورت نصب موتور محلی، fallback آفلاین نیز انجام می‌شود
- عبارت‌نامهٔ داخلی برای عبارت‌های شناخته‌شده، بدون نمایش ترجمهٔ ناقص یا مخلوط به‌عنوان نتیجهٔ کامل
- تاریخچهٔ ترجمه، پیشرفت و واژگان در حافظهٔ محلی دستگاه
- **موتور صوتی مستقل داخل APK** برای انگلیسی: Piper Amy Medium با اجرای Sherpa-ONNX و مدل float باکیفیت‌تر
- صدای زن انگلیسیِ عصبی، بدون استفاده از Android TTS، `speechSynthesis` یا هر سرویس ابری
- رابط فارسیِ سازگار با Android، بر پایهٔ Capacitor
- ساخت خودکار APK با GitHub Actions

## موتور صوتی داخلی

سیمرغ فقط صدای انگلیسی را بسته‌بندی می‌کند. مدل **Piper Amy Medium** یک صدای زن انگلیسی با بیان طبیعی‌تر است و نسخهٔ float آن در `android/app/src/main/assets/tts/tts-en.zip` قرار دارد. به‌دلیل افت شدید کیفیت نسخهٔ int8 در دستگاه واقعی، این نسخه برای وضوح گفتار از quantization استفاده نمی‌کند؛ در نتیجه APK بزرگ‌تر است، اما کیفیت بیان قابل‌قبول‌تر می‌شود. موتور با Sherpa-ONNX در native Android اجرا می‌شود و نمونهٔ صوتی را مستقیماً با `AudioTrack` پخش می‌کند.

این مسیر مستقل است: برنامه نه از موتور صوتی Android استفاده می‌کند، نه از مرورگر و نه از شبکه. هنگام اولین اجرا، فایل داخلی یک‌بار در فضای خصوصی برنامه باز می‌شود. اگر کاربر برای یک واژه فایل صوتی خودش را بارگذاری کرده باشد، همان فایل اولویت دارد. صدای داخلی فعلاً **فقط انگلیسی** است؛ برای نتیجهٔ فارسی پیام روشن نمایش داده می‌شود و fallback به Android یا مرورگر وجود ندارد.

موتور و مدل از پروژه‌های متن‌باز Sherpa-ONNX و Piper انتخاب شده‌اند. مجوز و لینک منابع در [`RESEARCH_NOTES.md`](./RESEARCH_NOTES.md) و [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md) ثبت شده است؛ این notices را همراه APK نگه دارید.

## ترجمهٔ آنلاین و حالت آفلاین اختیاری

در حالت عادی، برنامه ابتدا از API رایگان MyMemory برای ترجمهٔ آنلاین استفاده می‌کند. متن برای ترجمه به سرویس آنلاین ارسال می‌شود؛ محدودیت سرویس رایگان طبق مستندات MyMemory حداکثر ۵۰۰ بایت برای هر درخواست و حدود ۵۰۰۰ نویسه در روز برای استفادهٔ ناشناس است. API برای حفظ سازگاری با WebView از CORS باز استفاده می‌کند.

اگر اینترنت در دسترس نباشد یا کاربر حالت آفلاین را انتخاب کند، برنامه در صورت نصب بودن موتور بومی به آن fallback می‌کند. در حالت آفلاین متن از دستگاه خارج نمی‌شود. دریافت مدل Argos/CTranslate2 مستقل از Google Play services است و به‌صورت جداگانه انجام می‌شود.

منبع API آنلاین: https://mymemory.translated.net/doc/spec.php

## حجم APK

- فقط ABI `arm64-v8a` برای هدف گوشی‌های جدید و کاهش حجم ساخته می‌شود.
- موتور Sherpa-ONNX به‌صورت native داخل برنامه است و هیچ کتابخانهٔ صوتی دیگری بسته‌بندی نمی‌شود.
- تنها یک مدل صوتی انگلیسیِ float و دادهٔ phonemizer داخل APK است؛ مدل فارسی حذف شده است.
- R8 و حذف resourceهای بلااستفاده در debug و release فعال است.

## ساخت و اجرا

```bash
npm ci
npm run verify:translator
npm run sync
cd android
./gradlew assembleDebug
```

یا:

```bash
npm run build:android
```

پروژهٔ `android/` را می‌توان مستقیماً در Android Studio باز کرد. workflowهای موجود در `.github/workflows/` assets را همگام‌سازی و APK آزمایشی می‌سازند.
