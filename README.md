# Simorgh Irani Offline | سیمرغ

اپلیکیشن Android برای آموزش زبان انگلیسی، تمرین مکالمه و ترجمهٔ محلی **فارسی ↔ انگلیسی**.

## قابلیت‌ها

- ترجمهٔ آفلاین بر پایهٔ واژه‌های درس‌ها و عبارت‌نامهٔ داخلی؛ متن ناشناخته به اینترنت ارسال نمی‌شود
- مکالمه‌های آمادهٔ دوزبانه برای موقعیت‌های روزمره
- گفتار انگلیسی و فارسی با Text-to-Speech محلی Android و انتخاب صدای بدون نیاز به شبکه
- پیشرفت، تاریخچهٔ ترجمه و واژگان در حافظهٔ محلی
- رابط مناسب Android بر پایهٔ Capacitor
- ساخت خودکار APK آزمایشی با GitHub Actions

## آفلاین بودن و صداها

اپلیکیشن از API یا سرویس اینترنتی برای ترجمه استفاده نمی‌کند و مجوز اینترنت در manifest برنامه درخواست نشده است. مترجم از عبارت‌نامه و واژه‌های محلی برنامه استفاده می‌کند؛ عبارت‌های خارج از این واژه‌نامه با پیام روشن رد می‌شوند، نه اینکه به سرویس ابری فرستاده شوند. این قابلیت جایگزین مترجم عمومیِ تمام‌جمله‌ای نیست.

پخش گفتار فقط از صدای نصب‌شدهٔ Android استفاده می‌کند که `isNetworkConnectionRequired=false` باشد. دسترس‌پذیری صدای فارسی به موتور TTS و دادهٔ صوتی نصب‌شده روی دستگاه بستگی دارد و در همهٔ گوشی‌ها تضمین‌شده نیست. در صورت نبود صدا، در تنظیمات Android بخش Text-to-speech صدای محلی دستگاه را بررسی کنید؛ برنامه صدای ابری را جایگزین نمی‌کند.

## ساخت و اجرا

```bash
npm install
npm run sync
```

در Android Studio پروژهٔ `android/` را باز کنید، یا در محیط دارای Android SDK اجرا کنید:

```bash
cd android
./gradlew assembleDebug
```

workflowهای موجود در `.github/workflows/` برای همگام‌سازی assets و ساخت APK آزمایشی آماده‌اند.

برای تولید APK، JavaScript هنگام بسته‌بندی مبهم‌سازی و کد Android با R8 کوچک‌سازی/مبهم‌سازی می‌شود؛ فایل منبع خوانا در `www/index.html` باقی می‌ماند. این کار استخراج و بازخوانی را دشوارتر می‌کند، اما **هیچ APK سمت کاربر را نمی‌توان کاملاً غیرقابل استخراج یا مهندسی معکوس کرد**؛ اسرار یا کلیدهای حساس را داخل برنامه قرار ندهید.
